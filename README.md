# Portfólio técnico

Este repositório reúne apresentações técnicas públicas baseadas em inspeção de implementações privadas. Ele não replica código, configurações, históricos, credenciais, dados de clientes nem informações operacionais.

As descrições separam o que foi verificado no código daquilo que não é declarado aqui como funcionamento em produção.

## Projetos

- [BRWhats Platform](./brwhats-platform.md) — SaaS multi-tenant de atendimento, com TypeScript, Node.js, React, PostgreSQL e runtime conversacional.
- [BR Organiza](./br-organiza.md) — aplicação de organização financeira com Python, FastAPI, PostgreSQL, IA com saída estruturada e integração de pagamentos.
